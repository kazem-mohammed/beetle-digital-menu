BEETLE FOOD & DRINKS — DIGITAL MENU

Files
- index.html: website structure and SEO metadata
- style.css: responsive vintage-inspired styling
- script.js: menu data, category navigation and live search
- hero.jpg: supplied café photograph
- logo.jpg: supplied Beetle logo artwork
- menu-desserts.jpg, menu-juices.jpg, menu-hot-drinks.jpg, menu-espresso.jpg, menu-signatures.jpg: supplied menu artwork

Run locally
Open index.html in a modern browser. No server, npm, backend or build step is required.

Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload every file in this folder to the repository root (do not put them in a subfolder).
3. In Settings > Pages, select Deploy from a branch and choose the main branch / root folder.
4. Save. GitHub Pages will publish index.html as the homepage.

Notes
- All image files are in the same root folder as index.html.
- No restaurant phone, WhatsApp, address, map or social links were supplied, so none have been invented.
- Developer contact details are included in the footer as provided.
- Menu item names and prices are transcribed from the supplied images. For Turkish, French and Hazelnut Coffee, the source shows S / D prices.
- Google Fonts are optional; the site falls back to local serif and sans-serif fonts if unavailable.
