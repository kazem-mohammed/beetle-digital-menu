BEETLE FOOD & DRINKS — DIGITAL MENU

FILES
- index.html: website structure and content sections
- style.css: responsive styling, 3D depth and motion effects
- script.js: menu data, search, product detail dialog, social links and contact actions
- image files: kept beside index.html in this root folder

RUN
Open index.html in a modern browser. No backend, npm, build step or local server is required.

PUBLISH ON GITHUB PAGES
1. Create a GitHub repository.
2. Upload every file in this folder to the repository root (not the enclosing folder).
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.

EDIT RESTAURANT CONTACT DETAILS
Edit the restaurantInfo object near the top of script.js. Empty values are intentionally hidden.
The supplied Google Maps short link is used as an external directions link; no map iframe is embedded because no dedicated Maps Embed URL was supplied.

MENU ACCURACY
Menu names, prices and descriptions are transcribed from the supplied menu images. Please verify any source text that may be visually ambiguous before publishing.
